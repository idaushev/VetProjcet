# Ручная проверка перед выкладкой

Автотесты проверяют данные и права. Они **не видят раскладку, порядок действий
и то, что чувствует врач за планшетом** — на этом уже дважды ловились ошибки:
кнопки состояния пациента, вытянутые в столбик, и протокол, который негде было
заполнить. Поэтому перед выкладкой — этот список, руками.

Отмечать не «работает», а **что именно увидели**.

---

## 0. Подготовка

- [ ] Тестовый стенд: `start.bat`, база `data\vet-test.db` (боевую не трогаем).
- [ ] Проверять на ДВУХ ширинах минимум: планшет (834×1194) и десктоп (1280+).
      Телефон (390) — если правили формы.
- [ ] Ролей минимум две: администратор и врач (у них разный интерфейс).

---

## 1. Приём: сквозной путь

1. [ ] Новый приём из расписания и из карточки животного — открывается,
       владелец и животное подставлены.
2. [ ] Полоса аллергий видна **до** данных приёма. Если пусто — «Указать».
3. [ ] Вес, температура, показатели — три поля в одном ряду, подписи в одну
       строку, не переносятся.
4. [ ] Кнопки состояния пациента — одной строкой на десктопе, аккуратным
       переносом на планшете. **Не столбиком.**
5. [ ] Добавить услугу с протоколом → форма протокола открывается СРАЗУ,
       поверх приёма, с путём возврата «← Новый приём».
6. [ ] Заполнить, «Готово» → строка в «Результатах» стала «заполнен ·
       запишется вместе с приёмом», кнопка сменилась на «Изменить».
7. [ ] Удалить строку услуги из счёта → строка результата исчезла.
8. [ ] Вернуть услугу → заполненное **не потерялось**.
9. [ ] Сохранить → тост перечисляет, что записалось («протоколов: 1»).
10. [ ] Переоткрыть приём → результат «заполнен», лаборатория на месте.

## 2. Приём: то, что легко сломать

- [ ] Приложить фото и нажать «Отмена» → спрашивает про несохранённые данные.
      «Остаться» — файл цел, «Закрыть» — файла нет.
- [ ] Назначение: препарат, доза, путь, длительность → после сохранения на
      СЛЕДУЮЩЕМ приёме того же животного видно «Терапия идёт сейчас».
- [ ] Отменить курс с причиной → в списке «отменено», причина видна.
- [ ] Указать дату следующего приёма → после сохранения предлагает создать
      запись в расписании.
- [ ] «Назад» (жест или кнопка браузера) из открытого поверх окна закрывает
      ТОЛЬКО его, форма приёма остаётся.

## 3. Права

Под врачом без права «Справочники»:

- [ ] Настройки → карточки «Шаблоны протоколов» нет, кнопки «Добавить» у
      справочника диагнозов нет.
- [ ] Приём при этом заполняется нормально, подсказки диагнозов работают.

Под ролью «Склад»:

- [ ] В меню только «Справочник» и «Склад». Медкарты нет.
- [ ] Кабинета владельца в меню нет.

## 4. Каталог

- [ ] Создать позицию → сохраняется.
- [ ] Открыть её же, изменить цену и «Требует результата» → **сохраняется**
      (эта правка была сломана и чинилась; проверять каждый раз).
- [ ] Удаление ушло в меню «⋯», корзины в строке нет.

## 5. Планшет

- [ ] Нижняя панель: у врача «Приёмы», у регистратора «Животные».
- [ ] Открытый раздел подсвечен, «Ещё» не горит одновременно с ним.
- [ ] Горизонтальной прокрутки нет ни на одном разделе.
- [ ] Модалка приёма прокручивается, кнопки «Отмена/Сохранить» видны всегда.

## 6. Офлайн

- [ ] Выключить сеть (или остановить сервер): приём создаётся и сохраняется.
- [ ] Приложить файл офлайн → в списке «отправится при подключении».
- [ ] Включить сеть → в течение цикла синка запись и файл уезжают, статус в
      сайдбаре становится «Актуально».

## Если что-то не так

Снимок экрана помогает больше описания: программные замеры раскладку не видят.
Ошибку в интерфейсе искать в консоли браузера — сервер про неё может не знать
(так было с «maybeOfferAppointment is not defined»: приём сохранялся, ошибка
показывалась, в логе сервера пусто).

## 7. Несколько исследований по одной услуге

Клиника делает два УЗИ за приём (брюшная полость и сердце) — это два разных
протокола, а не один. Ломается тихо: второе исследование просто «не
заполняется», ошибок нигде нет.

- [ ] Добавить одну и ту же услугу с протоколом ДВАЖДЫ → окно открывается оба
      раза, второй раз ПУСТОЕ и озаглавлено «… №2».
- [ ] Заполнить оба по-разному → в блоке две строки с разными заключениями.
- [ ] Сохранить → тост «протоколов: 2», после переоткрытия оба на месте.
- [ ] В сохранённом приёме добавить третью такую же строку → «… №3», пустое.
- [ ] Удалить незаполненную строку → она уходит из блока; заполненные
      остаются (это медицинская запись, а не строка счёта).

## 8. Экран не «дрожит»

- [ ] Постоять на списке приёмов минуту, не трогая ничего: список НЕ
      перестраивается, прокрутка не уезжает.
- [ ] Набрать цену в позиции: блок результатов не моргает на каждый символ.
- [ ] Открыть форму приёма и подождать цикл синхронизации: список за спиной
      формы не перерисовывается.

Проверять на стенде С ДАННЫМИ: на пустой базе дрожания не видно, потому что
сервер не присылает ни надгробий, ни изменений.

## 9. Правка внесённого результата

- [ ] В блоке результатов приёма у заполненной строки ДВЕ кнопки: «Открыть» и
      «Изменить». На планшете (834) обе в одну строку, без переноса.
- [ ] То же в карточке животного, в списке «Анализы и результаты»: «Изменить»
      рядом со «смотреть», клик по кнопке НЕ открывает просмотр.
- [ ] Открыть заполненный результат → в карточке тоже есть «Изменить результат».
- [ ] Нажать → форма открылась С ЗАПОЛНЕННЫМИ значениями, вверху предупреждение
      «Результат уже внесён …», кнопка называется «Сохранить исправление».
- [ ] Исправить цифру и заключение → тост «Результат исправлен».
- [ ] Переоткрыть → внизу карточки «Внесён … , исправлен …» с ВРЕМЕНЕМ, а в
      списке результатов приёма у строки приписка «· исправлен».
- [ ] Дата поступления результата НЕ изменилась (по ней сортируется кабинет
      владельца и строится хронология лечения).

## 10. Бланки протоколов доехали до планшета

- [ ] Настройки → Шаблоны протоколов: четыре стартовых бланка (ОАК собаки,
      ОАК кошки, биохимия, УЗИ брюшной полости).
- [ ] Открыть бланк УЗИ в приёме → восемь разделов, у «Мочевого пузыря»
      наполнение списком, толщина стенки числом с подсказкой нормы,
      содержимое строкой, взвесь и конкременты галочками, описание текстом.
- [ ] У врача БЕЗ права «Справочники» бланки всё равно открываются
      (право ограничивает правку, а не чтение).
